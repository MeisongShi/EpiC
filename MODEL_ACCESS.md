# Model and API access

## Current status

The EpiC client is public. Access to live model inference is controlled and is not
automatically granted by downloading this repository.

The institutional access channel has not yet been announced. Please watch this
repository for an access notice. Do not post credentials, private data, or unpublished
materials in a GitHub Issue.

An approved user receives:

- an API base URL;
- a personal or project API key;
- applicable usage terms and rate limits;
- the currently supported model, cell-type, and input vocabularies.

Do not share API keys. Do not place them in notebooks, configuration files, command
history, Issues, or source control. Keys may be revoked if they are exposed.

## Model artifacts

This repository does not distribute model weights or architecture code. Any future
Hugging Face or other artifact release will be announced here only after separate
intellectual-property, licensing, security, and scientific review.
