# Security policy

## Reporting a vulnerability or exposed credential

Do not open a public Issue for credentials, private service details, unpublished model
artifacts, or vulnerabilities. Use GitHub's private vulnerability reporting feature
for this repository. Repository administrators should enable that feature before
publication. Include only the minimum information required to reproduce the issue.
Never attach real genomic data, model weights, private logs, API keys, or personal
information.

If an API key is exposed, revoke or rotate it immediately.
